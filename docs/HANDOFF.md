## 容易再次踩的坑

- 每次换 Wi-Fi 都重新读取服务器电脑 IP；旧聊天里的 IP 不能直接复用。校园网可能隔离设备，必要时使用允许互访的个人热点。
- 本机启动脚本监听 127.0.0.1；手机联调脚本监听 0.0.0.0。根路径 404 正常，检查 `/health`，接口页 `/docs`。
- GitHub 是代码托管，不是这个 Python 服务器的运行地址；两人不在同一局域网时不能直接访问对方的私有 IP。
- 当前原生 OpenCV 框架面向真实 iPhone，不支持 Apple Silicon arm64 模拟器构建。
- S3 内置 PNG 用 `.bin` 扩展名保存；不能随意改回 `.png` 让 Xcode 转成 CgBI。
- 开发签名需本人配置、可能到期；不共享 Apple 账号或私钥。
- 普通日志虽不含正文，也可能含设备名称、网络信息；默认不上传。需要协作分析时先审阅，记录采集条件，并保留失败记录。
